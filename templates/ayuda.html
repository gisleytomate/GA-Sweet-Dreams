Aprende a administrar nuestro catálogo de deliciosos postres.

♡ ¿Cómo funciona nuestra aplicación?

Bienvenido al sistema de administración de G&A Sweet Dreams. Aquí podrás registrar, consultar, editar y eliminar los productos de nuestra pastelería.

Utiliza únicamente información ficticia durante esta práctica académica.

🍰 1. Registrar un postre

Ingresa el nombre del postre, selecciona su categoría y establece su estado. Después presiona el botón Guardar postre.

♡ 2. Consultar el catálogo

En la sección Nuestro catálogo podrás visualizar todos los productos registrados, sus categorías y disponibilidad.

✨ 3. Editar un producto

Selecciona el botón Editar del producto que deseas modificar. Cambia los datos necesarios y guarda los cambios.

🗑️ 4. Eliminar un producto

Presiona Eliminar en el producto que deseas borrar. El sistema solicitará una confirmación antes de eliminarlo.

💻 5. API JSON

Nuestra aplicación también cuenta con una API que permite consultar, registrar, actualizar y eliminar productos mediante solicitudes HTTP.

Método Ruta Función
GET /api/productos Consultar catálogo
GET /api/productos/<id> Consultar producto
POST /api/productos Registrar producto
PUT /api/productos/<id> Actualizar producto
DELETE /api/productos/<id> Eliminar producto

Nota: Esta versión es exclusivamente académica. La API todavía no requiere inicio de sesión.
